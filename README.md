Aplicación que pide al usuario que identifique su usuario y el archivo que desea ver. 
Primero el usuario introduce el archivo y el programa lo valida. Si la validación no es correcta, vuelve a solicitarlo. Si la validación es correcta, sigue la ejecución, solicitando al usuario el nombre del archivo que desea ver. De la misma manera, se valida la entrada del usuario. En caso de no validarse el formato del archivo, se vuelve a solicitar. Si es correcto, entonces se intenta mostrar por pantalla. Si el archivo no existe, lo notifica con un mensaje. En caso de existir, muestra el contenido del archivo por pantalla.
Para cualquier resultado de la validación, se queda un registro hecho en un archivo .log.
